# 博客访问分析

前台使用同域 `/api/analytics/collect` 接口，后台为 `/admin/analytics`，数据写入 `007_analytics.sql` 的浏览与事件两张表。使用本地打包的 `web-vitals` 标准构建收集 LCP、INP、CLS、FCP、TTFB，不加载第三方统计脚本或发送到第三方服务。

## 统计口径

- PV：每个随机页面标识一条记录。累计心跳、页面离开和重复上报只更新原记录，事件以独立 UUID 去重。
- UV：180 天匿名浏览器 Cookie 的哈希在所选时间内的去重数；不跨设备识别。Cookie 为 HttpOnly、SameSite=Lax，HTTPS 下为 Secure。
- 会话：30 分钟不活跃后创建新的匿名会话。页面在后台超过 30 分钟后重新激活，会建立新的浏览记录。
- 活跃停留：页面可见且 60 秒内有交互，或页面内媒体正在播放的时间。后台闲置不计；每秒累计，30 秒批量上报，离开时使用 keepalive。
- 跳出率：单页、活跃不足 10 秒且无有效交互的会话占比。
- 阅读完成：滚动深度达到 90% 且活跃至少 10 秒，是阅读深度的近似指标。
- 来源和推广活动：取所选区间内会话的第一个浏览。UTM source/medium/campaign 仅保留受限字符；外部来源只留域名，站内来源只留公开路径。
- 页面类型或精确路径筛选后，会话相关指标也只计该范围内的浏览。入口、最后浏览页和路径流向均以所选范围为准，最后一页不表示会话已经结束。
- 趋势按北京时间分日，支持最近 180 天内最多 90 天的查询；对比前一个等长时段。实时人数按最近 5 分钟计算，不受日期区间限制。
- 性能使用真实用户样本的 P75。缺少样本显示空值，不能以 0 代替；各浏览器支持的指标不同。

## 埋点范围

页面访问、站内导航、外链、搜索次数与长度、筛选、图片放大、音视频播放、作品链接分享、下载、主题切换、阅读材质、JavaScript/资源/Promise 异常类别。文章、碎碎念、摄影、链接和 PPT 的公共布局均加载采集器。

管理员和登录页不加载采集器。有效登录管理员浏览前台也不计入，DNT/GPC、webdriver 和常见机器人忽略。统计从上线后的实际访问开始，不补造历史数据。浏览器阻止脚本、网络失败和退出选择会影响覆盖率。

`collect` 的 204 表示请求已处理，不一定计入统计。响应头 `X-Analytics-Status` 的 `recorded` 表示入库；`ignored-admin` 表示已登录站长，`ignored-privacy` 表示 DNT/GPC，`ignored-bot` 表示机器人，`ignored-path` 表示不采集的页面，`disabled` 表示全站停用。被排除的浏览器收到结果后停止本页后续上报。后台持续显示站长排除提示；可用未登录的无痕窗口访问公开页面验证，等待最多 30 秒后刷新看板。

不保存原始 IP、完整 User-Agent、搜索词、键盘内容、表单正文、错误信息/堆栈、URL 查询参数或片段。采集前即清理来源 URL 和推广值。数据库只保留匿名标识哈希及公开路径；搜索路由中的关键词替换为 `[query]`。国家/地区只使用源站收到的 Cloudflare 标签，不调用外部 IP 画像服务，缺少时为未知。

## 部署与维护

1. 备份数据库，并运行 `npm run db:setup` 应用 `007_analytics.sql`。
2. 构建并发布网站。后台入口和统计接口沿用现有管理员登录与防缓存措施。
3. 安装 `deploy/rain-blog-analytics-retention.service`、`.timer`，启用 timer，每日按北京时间清理 180 天前的浏览记录，事件由外键级联清理。
4. `ANALYTICS_ENABLED=0` 可停用采集；已有数据和后台查询保留。回滚到未包含清理脚本的旧版本时，同时停用该 timer。

接口校验同源、请求体最多 32 KiB、每批最多 20 个事件，使用枚举事件与目标白名单、匿名浏览器归属校验和进程内限流。使用累计值更新心跳，避免重复累计停留与滚动；单次活跃时间也受服务器观测时长约束。只读看板按筛选项缓存 30 秒，最多 20 份，不在客户端开放原始明细或个人访问轨迹。
