# 后台写作空间

文章编辑页默认进入单栏写作；正文以 CodeMirror 6 编辑，数据仍是原来的 Markdown，草稿、发布、预览与历史版本继续使用现有 API。

- `Aa` 中调整宋体 / 无衬线、字号、打字机模式、段落聚焦及深色纸面，偏好保存在当前浏览器。
- 专注模式收起辅助操作，按 Escape 退出。选中文字可呼出格式工具条；⌘ / Ctrl + B 加粗，⌘ / Ctrl + S 保存。
- 图片支持粘贴、拖入及从媒体库选择，上传沿用原来的压缩与存储流程。上传期间暂停保存与发布；替换占位时使用编辑器事务映射光标，不覆盖上传期间输入的文字。
- “发布设置”展开文章属性；确认发布后才更新公开文章。完整草稿预览、版本恢复与 Markdown 导出仍然保留。

输入会保存到浏览器本地，即使尚未填写标题；有标题后再防抖保存到服务器。重新打开时先选择恢复或忽略本地草稿，选择前不会用服务器内容覆盖待恢复内容。较旧本地草稿会提示服务器已有更新。保存成功仅清除与请求快照一致的本地内容，保存期间继续输入会保留新的本地快照。重新联网会重试保存；版本冲突保持服务器原有的保护机制。

浏览器存储不可用时会明确提示。关闭页面前保留光标与滚动位置；本地恢复与写作偏好仅作用于当前浏览器。请勿把浏览器本地草稿当作跨设备同步或长期备份。

验证包括 Markdown 字数、段落边界、本地草稿格式与旧格式兼容、图片占位处理，以及浏览器中的保存失败恢复、慢速保存时继续输入、撤销与预览切换。浏览器自动化输入不等同于真实中文输入法的人工验收。
