# 后台写作空间

文章编辑页默认进入单栏写作；正文以 CodeMirror 6 编辑，数据仍是原来的 Markdown，草稿、发布、预览与历史版本继续使用现有 API。

- `Aa` 中调整宋体 / 无衬线、字号、打字机模式、段落聚焦及深色纸面，偏好保存在当前浏览器。
- 专注模式收起辅助操作，按 Escape 退出。选中文字可呼出格式工具条；⌘ / Ctrl + B 加粗，⌘ / Ctrl + S 保存。
- 图片支持粘贴、拖入及从媒体库选择，上传沿用原来的压缩与存储流程。上传期间暂停保存与发布；替换占位时使用编辑器事务映射光标，不覆盖上传期间输入的文字。
- “发布设置”展开文章属性；确认发布后才更新公开文章。完整草稿预览、版本恢复与 Markdown 导出仍然保留。

输入停顿约 1.2 秒后自动保存到服务器，包括无标题正文和未填完的发布信息；发布时才检查标题、路径和链接。另一台设备登录后，在文章“草稿箱”打开继续编辑；已发布文章的未发布修改也列入草稿箱，点击发布更新才改变公开正文。

保存请求按顺序执行，保存期间可以继续输入。新稿使用稳定 UUID，响应丢失时先重试同一快照，再保存后续文字，不重复创建。版本冲突保留本机副本，选择重新打开服务器草稿后可核对、恢复或忽略本机内容。保存失败会明确提示，重新联网或点击“重试保存”可继续同步。

浏览器还保留未同步的本机恢复副本，关闭或隐藏页面时尽力提交草稿并保存光标位置；离线或上传中的内容应等待“已保存到服务器”后再换设备。浏览器存储不可用时会明确提示。本机恢复、光标和写作偏好仅作用于当前浏览器。

验证包括 Markdown 字数、段落边界、本地草稿格式与旧格式兼容、图片占位处理，以及浏览器中的保存失败恢复、慢速保存时继续输入、撤销与预览切换。浏览器自动化输入不等同于真实中文输入法的人工验收。

## 碎碎念

本站碎碎念也使用同一编辑器和 `Aa` 偏好，支持专注、打字机、段落聚焦与阅读预览。新建内容默认为轻量 Markdown；旧内容继续作为纯文本编辑，只有主动切换正文格式才转换。格式标识随已清理的正文 HTML 保存，不批量改写旧数据，也不需要数据库迁移。

配图继续通过上传、粘贴、拖入及媒体库添加，保持九张上限；正文中的 Markdown 图片按链接显示。输入停顿约 1.2 秒后自动保存到服务器，字数和保存状态始终可见。新建和已发布内容的未发布修改均进入草稿箱，另一台设备登录后可以继续编辑。已发布字段仅在点击“更新发布”后替换；“撤回发布”是独立的显式操作。本机恢复副本继续保留，网络恢复后可以重试同步。

同步请求按顺序执行，保存期间可以继续输入。新草稿使用稳定 UUID，重试不会重复创建；版本冲突保留本机内容并提示重新打开服务器草稿，不自动覆盖另一台设备的修改。

本站新建内容和历史随记都能编辑或删除，操作位于每条卡片顶部，写作区顶部也有删除入口。删除确认后只移入回收站，保留正文和云端草稿；恢复后为草稿，不会直接重新公开。历史随记保留原来源和标签；正文未改动时保留原 HTML 排版和链接，原有配图可继续使用。

云端草稿使用 `008_moment_drafts.sql` 的独立表，不改写已发布正文；发布后删除对应草稿。通用数据库备份通过表清单自动包含新表。部署前先完成数据库备份并应用新增迁移。
