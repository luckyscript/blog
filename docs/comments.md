# 文章与碎碎念评论

文章正文底部和碎碎念详情页提供访客留言；碎碎念列表的“留言”链接跳转到详情页。无需注册，昵称必填，邮箱选填，仅管理员可见。评论作为纯文本展示，不执行 HTML 或 Markdown。新评论一律待审核，审核通过后才返回给公开接口及页面。

`/admin/comments` 集中管理两类评论，可按来源、待审核、已公开和回收站筛选。支持审核通过、撤回公开、博主回复、删除与恢复。回复只针对一级评论，博主回复直接公开并带“博主”标识；访客回复仍需审核。删除一级评论会隐藏整条对话，恢复到待审核后仍需重新批准。版本号防止多个后台窗口互相覆盖。

公开接口 `/api/comments/{post|moment}/{uuid}` 只接受本站 JSON 提交，并检查目标已公开（含时间、碎碎念来源启用及去重状态）。使用现有 Turnstile 配置，独立 action 为 `comment-submit`，不能复用登录令牌。提交频率按地址的 HMAC 摘要限制为十分钟十次，数据库不保存原始地址；过期限流记录会清理。请求体及昵称、正文等字段均有限额，蜜罐字段拦截简单自动填表。

新表由 `009_comments.sql` 创建：评论及短期限流记录自动纳入现有数据库全量备份。文章和碎碎念下架后，关联评论停止展示和接收；软删除内容或评论不会清除已有评论。草稿预览页不显示评论。回滚代码时保留新表和数据。

验证：独立 MySQL/HTTP 检查审核隔离、邮箱保密、HTML 转义、访客和博主回复、权限与来源校验、版本冲突、删除恢复、目标隐藏、去重和限流。Turnstile action 隔离使用受控响应单测，集成测试仅在本机隔离数据库使用官方测试密钥。
